# SolidnaWitryna

Маркетинговий сайт solidnawitryna.pl (Next.js App Router + TypeScript + Tailwind).

- План сайту: [`docs/plan.md`](docs/plan.md) — джерело правди для змісту.
- Токени і компоненти живуть у коді.

## Запуск

```bash
npm install
npm run dev
```

Відкрити [http://localhost:3000](http://localhost:3000).
